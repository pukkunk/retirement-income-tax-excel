# 退職所得の計算 Excel

退職金を受け取った場合の退職所得、所得税、住民税、手取額を計算するExcelファイルです。

入社日と退職日を入力することで勤続年数を算出し、勤続年数をもとに退職所得控除額を計算します。

さらに退職金額を入力することで、退職所得に対する所得税・復興特別所得税、住民税、および退職金の手取額を算出できます。

## 主な機能

* 入社日、退職日から勤続年数を算出
* 勤続年数から退職所得控除額を算出
* 退職金額を入力
* 課税退職所得金額を算出
* 所得税・復興特別所得税を算出
* 住民税を算出
* 退職金の手取額を算出

## 計算の流れ

```text
入社日
  ↓
退職日
  ↓
勤続年数
  ↓
退職所得控除額
  ↓
退職金額を入力
  ↓
退職所得を計算
  ↓
所得税・復興特別所得税
  ↓
住民税
  ↓
手取額
```

## 退職所得控除額

退職所得控除額は、勤続年数に応じて計算します。

### 勤続年数20年以下

```text
40万円 × 勤続年数
```

ただし、計算した金額が80万円未満の場合は80万円となります。

### 勤続年数20年超

```text
800万円 ＋ 70万円 ×（勤続年数－20年）
```

勤続年数に1年未満の期間がある場合は、1年に切り上げて計算します。

## 退職所得の計算

一般的な退職所得については、次の計算式を使用します。

```text
（退職金額 － 退職所得控除額）× 1/2
```

この金額をもとに所得税・復興特別所得税および住民税を計算します。

## 注意事項

このExcelは、退職金に関する税額を概算するための計算ツールです。

実際の税額は、退職金の種類、勤続期間、他の退職手当等の受給状況、退職所得控除額の調整などによって異なる場合があります。

特に、企業型確定拠出年金（DC）の一時金など、他の退職手当等を受け取る場合には、退職所得控除額の計算に影響する場合があります。

実際の申告・納税については、国税庁の最新情報や勤務先から提供される資料等を確認してください。
